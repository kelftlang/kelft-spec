# Contributing

Language, runtime, and compiler corrections belong in the
[public compiler repository](https://github.com/kelftlang/kelft). Include the
specification page, compiler commit, minimal example, expected behavior, and
observed compiler output. This website imports its specification from that repository.

Website improvements belong in this repository. Edit `pages/`, site configuration,
or tooling; do not edit imported `spec/` or `compiler-inputs/` files directly.
Synchronize upstream changes using the [maintainer guide](docs/maintaining.md).
Committed/released snapshots are immutable.

Software contributions use MIT OR Apache-2.0; prose uses CC-BY-4.0; designated
copyable examples use MIT-0. Preserve third-party notices. Sign off commits with
`git commit -s` under [DCO 1.1](DCO). Contributors retain ownership; no CLA or
assignment is required. See [licensing](docs/licensing.md).
